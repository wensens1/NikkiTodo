# NikkiTodo · 暖暖待办

一个 Q 版桌面待办 + 桌宠小工具，PyQt6 开发，Windows 平台。粉色圆角卡片、无边框透明窗口，平时收成一只桌宠贴在屏幕边上，到点弹出气泡提醒。

当前版本：**v1.7.3（发布版 1.0）**

![桌宠立绘](assets/char_stand.png)

## 功能特性

### 待办管理

- **快速新建**：顶部输入框打字，回车即可添加；`Ctrl+Enter` 换行。
- **提醒时间**：新建时点铃铛，或双击待办、点时间胶囊修改；日历带「今天」胶囊，可直接敲四位数字填时间。
- **双击编辑**：双击条目修改标题与提醒时间。
- **完成 / 置顶 / 删除**：圆圈打勾完成，收入底部「已完成」折叠栏；图钉置顶（不参与排序）；垃圾桶删除。
- **三种排序**：按创建时间、按提醒时间、自定义顺序（长按 0.2 秒上下拖拽换位）。
- **全局查找**：`Ctrl+F` 调出独立弹窗，同时搜索待办与便签（标题、正文），命中关键词高亮，回车跳下一个；命中已完成区会自动展开定位。
- **右键复制**：右键待办标题直接复制到剪贴板。
- **粘贴净化**：从网页、Word、微信粘贴时只取纯文本，不带原有的字号、颜色、加粗、背景。

### 提醒机制

- **气泡卡片**：到点在暖暖身边弹出圆角气泡，显示标题与提醒时间。
- **卡片操作**：
  - **稍后提醒**：推迟 10 / 30 / 60 分钟，只影响本次，不改动下次正常提醒。
  - **完成**：直接打勾完成这条待办。
  - **× 关闭**：本次不再提醒，待办仍留在列表。
  - **− 收成星星**：气泡缩成星星挂在桌宠旁，点星星还原为气泡。
- **右键菜单**（气泡、星星通用）：一键打开所有星星、一键缩小所有气泡、关闭此提醒、关闭目前所有提醒。
- **重复提醒**：每日 / 每周 / 每月 / 每年 / 工作日（自动跳过周末）。
  - 小月自动截断到月末（1 月 31 日 → 2 月 28 日）；闰年 2 月 29 日在平年落到 2 月 28 日。
  - 防堆积：过期未完成的不补历史提醒，直接滚到下一轮；已完成的复位后进入下一周期。
- **排布**：多条提醒同时到点时竖排 / 分列排列，不压任务栏；桌面放不下时从最前面开始自动收成星星腾地方。
- **落点三态**：桌宠在场贴暖暖左侧；只有窗口时先自动收成桌宠再贴暖暖；窗口和桌宠都不在时落桌面右下角，从下往上排。

### 便签

- **抽屉式侧栏**：便签列表平时缩进卡片背后，鼠标悬停或键盘 Tab 聚焦时滑出。
- **多页签管理**：新建、单击切换、双击重命名、右键删除、长按拖拽排序，支持无限添加。
- **自动保存**：内容改动即写盘，无需手动保存。
- **右键编辑菜单**：撤销 / 重做 / 剪切 / 复制 / 粘贴 / 删除 / 全选，不可用项自动置灰；粘贴同样只取纯文本。

### 窗口与桌宠

- **形态切换**：右上角「−」收成桌宠，点击桌宠或托盘图标展开回窗口。
- **桌宠缩放**：鼠标悬停桌宠，滚轮等比放大缩小（最小 0.3 倍）。
- **自由拖拽与缩放**：按住空白处拖动；右下角斜纹拉柄调整窗口大小；位置和尺寸始终锁进屏幕可用区，不会拖出桌面、不盖任务栏。
- **贴边翻面**：窗口贴到屏幕左边缘时，侧栏胶囊列自动翻到右侧防止被挡，腾出空间后翻回。
- **四角贴边展开**：桌宠贴角时展开窗口，卡片边贴对应角（优先级：左上 > 左下 > 右上 > 右下）。
- **贴边自动缩小**：设置中可开启，贴边后鼠标移开自动收成桌宠（默认关闭）。
- **位置兜底**：多显示器拔屏、分辨率变化等导致保存位置越界时，重启后窗口自动钳回可见区，不会藏到屏外。

### 托盘与设置

- **后台运行**：点 × 关闭窗口后程序继续在托盘运行，提醒照常弹出。
- **托盘操作**：单击在窗口 / 桌宠间切换，双击回到上一次形态；右键菜单：显示待办窗口、桌宠形态、开机自启、帮助文档、退出。
- **设置项**：全局字号（微 / 小 / 中 / 大）、待办排序方式、贴边自动缩小开关、开机自启。

## 快速开始

### 方式一：下载打包好的 exe（普通用户）

在 GitHub Releases 页面下载 `NikkiTodo.exe`，双击即可运行，无需安装。

> 首次打开若 Windows 提示「已保护你的电脑」，点「更多信息」→「仍要运行」即可（程序未做数字签名）。

### 方式二：从源码运行

环境要求：Windows、Python 3.13。

```bat
pip install -r requirements.txt
python main.py
```

也可以双击 `run.bat` 启动。命令行参数：

- `python main.py --window`：强制以主窗口启动
- `python main.py --pet`：强制以桌宠启动
- 不带参数：按上次保存的形态启动

## 从源码打包 exe

```bat
pyinstaller --noconfirm --clean --onefile --windowed --name NikkiTodo --icon app.ico --add-data "assets;assets" main.py
```

打包产物在 `dist/` 目录；对外发布的 exe 放在 `release/`（该目录已被 `.gitignore` 忽略，不入库）。立绘、图标、SVG 素材都会内嵌进单文件 exe，单独拷贝 exe 即可运行。

## 目录结构

```
NikkiTodo/
├── main.py               # 程序入口：单实例守护、托盘、提醒调度、开机自启
├── data_store.py         # 本地 JSON 持久化
├── repeat.py             # 重复提醒周期推进与到点判定
├── search.py             # 待办 / 便签查找匹配
├── theme.py              # 配色变量与全局 QSS 主题
├── ui_icons.py           # 矢量图标绘制
├── ui_utils.py           # 通用控件与工具函数
├── widgets/              # 界面组件
│   ├── main_window.py    # 主窗口
│   ├── pet_window.py     # 桌宠与提醒气泡 / 星星
│   ├── todo_item.py      # 待办条目
│   ├── dialogs.py         # 编辑待办 / 设置 / 查找弹窗
│   ├── dialog_base.py     # 弹窗外壳
│   ├── controls.py       # 自定义控件
│   ├── text_menu.py      # 便签正文右键菜单
│   ├── help_dialog.py    # 内置帮助文档
│   └── __init__.py
├── assets/               # 立绘、图标、SVG 素材
├── docs/
│   ├── 使用说明.txt       # 面向使用者的图文说明
│   └── 开发日记/         # 各版本开发记录
├── release/              # 预打包 exe（不入库）
├── app.ico               # 程序图标
├── NikkiTodo.spec        # PyInstaller 打包配置
├── requirements.txt      # 依赖清单
└── run.bat               # 源码启动脚本
```

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Enter` | 确认输入 / 添加待办 |
| `Ctrl+Enter` | 输入框内换行 |
| `Ctrl+F` | 查找待办 / 便签（回车跳下一个，`Esc` 关闭） |
| 双击待办 | 编辑待办 |
| 右键待办 | 复制标题到剪贴板 |

## 数据与隐私

- 所有数据保存在程序同级目录的 `data.json`（待办、便签、设置），不写入 AppData，不联网、不上传。
- `data.json`、`data.json.bak`、`app.lock` 为运行时本地文件，已在 `.gitignore` 中忽略，不会进入仓库。
- 换电脑或迁移文件夹时，把程序和 `data.json` 一起拷贝即可保留数据；卸载直接删除整个文件夹。
